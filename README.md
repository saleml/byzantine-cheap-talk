# Communication Enables Cooperation in LLM Agents

This repository contains the code for the paper [**"Communication Enables Cooperation in LLM Agents: A Comparison with Curriculum-Based Approaches"**](https://arxiv.org/abs/2510.05748) (EACL 2026).

## Key Findings

1. **Communication dramatically improves coordination**: One-word "cheap talk" increases Stag Hunt cooperation from 0% to 48.3% in heterogeneous agent groups.
2. **Curriculum learning is fragile**: Our curriculum reduced agent payoffs by 27.4% vs. a no-training baseline, demonstrating that curricula emphasizing defection-equilibrium games can induce "learned pessimism."

## Source Files Explained

### `src/engine.py`
Core game engine with two main classes:
- **`GameEngine`**: Runs single games, handles LLM API calls via DeepInfra/OpenAI, parses JSON responses
- **`CurriculumEngine`**: Orchestrates multi-stage curriculum experiments, generates inter-stage lessons via Claude, tracks accumulated lessons across stages

### `src/games.py`
All game implementations as Python classes:
- **`StagHuntGame`**: 4-player Stag Hunt coordination game
- **`StagHuntWithCommunication`**: Adds one-word cheap talk phase before action
- **`PublicGoodsGame`**: One-shot 4-player PGG with optional punishment
- **`IteratedPublicGoodsGame`**: Multi-round PGG (target task for curriculum)
- **`IteratedPublicGoodsGameWithCommunication`**: IPGG with cheap talk channel
- **`IteratedPrisonersDilemma`**: 2-player IPD (curriculum stage 1)
- **`NPlayerIteratedPrisonersDilemma`**: 4-player IPD (curriculum stage 2)

### `src/prompts.py`
LLM prompt templates for each game. Each template includes:
- Game rules and payoff structure
- Game history from previous rounds
- Instructions for Chain-of-Thought reasoning
- Required JSON output format

### `src/main_orchestrator.py`
Main CLI entry point. Key arguments:
- `--experiment standard|curriculum`: Experiment type
- `--curriculum-config PATH`: Path to curriculum JSON
- `--games GAME1 GAME2`: Specific games to run
- `--trials N`: Number of trials per condition

### `src/engine_claude_lessons.py`
**`ClaudeLessonGenerator`**: Uses Claude Opus 4.1 to analyze game logs and generate strategic lessons. Lessons are prepended to agent prompts in subsequent curriculum stages.

## Scripts Explained

### `scripts/run_curriculum_static_lesson.py`
**Neutral Lesson Ablation (Table 3 in paper)**: Runs curriculum with generic non-strategic lessons instead of Claude-generated ones. Isolates the effect of lesson content vs. game exposure.
```bash
python scripts/run_curriculum_static_lesson.py --config config/curriculum_full.json --trials 30
```

### `scripts/run_ipgg_baselines.py`
**IPGG Communication Experiment (Section 4.3)**: Runs IPGG+Punishment with and without cheap talk channel. Tests if communication helps in social dilemmas.
```bash
python scripts/run_ipgg_baselines.py --trials 10  # Runs both plain and comm conditions
```

### `scripts/run_model_generalization.py`
**SOTA Model Generalization (Appendix A.10)**: Tests Stag Hunt and IPGG with frontier models (GPT-4o, o1-preview, etc.) to validate findings generalize beyond open-source models.
```bash
python scripts/run_model_generalization.py --trials 5
```

### `scripts/run_strong_models_smoke.py`
Quick smoke tests with stronger models (DeepSeek-R1, GPT-4o-mini) on communication variants.

### `scripts/run_extra_trials.py`
Utility to add more trials to existing curriculum conditions without re-running from scratch.

## Analysis Files Explained

### `analysis/enhanced_analyzer.py`
**Main analysis script** that generates all paper figures. Key methods:
- `analyze_curriculum_trajectories()`: Round-by-round cooperation data
- `compare_final_performance()`: Condition comparison statistics
- `analyze_pilot_games()`: Stag Hunt + PGG baseline analysis
- `generate_enhanced_visualizations()`: Creates all 4 paper figures

### `analysis/unified_parser.py`
Parses raw trial JSONs from `results/` into a unified `unified_consolidated_data.jsonl` format for analysis.

### `analysis/qualitative_sampler.py`
Extracts agent reasoning traces for qualitative analysis (Section 5.2). Samples rationales showing learned pessimism, heuristic overfitting, etc.

### `analysis/qualitative_analyzer.py`
**`QualitativeAnalyzer`**: Implements PGG failure mode taxonomy (FEAR, GREED, RATIONAL_CHOICE, etc.) and communication pattern analysis.

### `analysis/metrics.py`
**`MetricsCalculator`**: Computes cooperation rates, payoffs, punishment usage, and other metrics from parsed data.

### `analysis/visualizer.py`
**`ExperimentVisualizer`**: Generic visualization tools for cooperation rates, payoff distributions, etc.

### `analyze_curriculum_benefits.py` (root)
Standalone script to analyze curriculum learning benefits from partial results. Useful for quick checks during experiment runs.

## How to Reproduce Paper Results

### Prerequisites

```bash
pip install pandas numpy matplotlib seaborn scipy anthropic openai tqdm
export DEEPINFRA_API_KEY="your_deepinfra_key"
export ANTHROPIC_API_KEY="your_anthropic_key"  # For lesson generation
```

### 1. Run Curriculum Experiments (Table 2)

```bash
# Full Curriculum: IPD → N-IPD → 3-round IPGG → 10-round IPGG+P
python3 src/main_orchestrator.py --experiment curriculum \
    --curriculum-config config/curriculum_full.json --trials 30

# Scrambled Curriculum: Same games, random order
python3 src/main_orchestrator.py --experiment curriculum \
    --curriculum-config config/curriculum_scrambled.json --trials 30

# Direct Precursor: 3-round IPGG → 10-round IPGG+P only
python3 src/main_orchestrator.py --experiment curriculum \
    --curriculum-config config/curriculum_direct_precursor.json --trials 30

# Control Group: 10-round IPGG+P with no prior training
python3 src/main_orchestrator.py --experiment curriculum \
    --curriculum-config config/control_group.json --trials 30
```

### 2. Run Stag Hunt Experiments (Table 1)

```bash
# Stag Hunt without communication
python3 src/main_orchestrator.py --games stag_hunt --trials 30

# Stag Hunt with one-word cheap talk
python3 src/main_orchestrator.py --games stag_hunt_communication --trials 30
```

### 3. Run Ablation Studies (Table 3)

```bash
# Neutral Lesson Ablation
python scripts/run_curriculum_static_lesson.py --config config/curriculum_full.json --trials 30

# IPGG with Communication (Section 4.3)
python scripts/run_ipgg_baselines.py --trials 10
```

### 4. Generate Figures

```bash
# Parse all trial data into unified format
python3 analysis/unified_parser.py

# Generate all paper figures
python3 analysis/enhanced_analyzer.py --summary

# Output saved to analysis/figures/
```

## Game Rules Summary

### Stag Hunt (4-player)
- Actions: "Hunt Stag" or "Hunt Hare"
- Payoffs: All hunt stag = 10 each; any hunt hare = hare hunters get 3, stag hunters get 0
- Tests coordination under risk

### IPGG with Punishment (4-player, 10 rounds)
- Each player gets 20 tokens/round
- Contribute 0-20 to public pot; pot multiplied by 1.6x and split equally
- Punishment phase: spend 1 token to reduce another player's payoff by 3
- Tests cooperation with norm enforcement

### Prisoner's Dilemma
- 2-player (stage 1) or 4-player (stage 2) variants
- Standard cooperate/defect payoff matrix
- Tests basic reciprocity learning
